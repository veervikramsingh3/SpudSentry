About PotatoPathFinder

Learn about our project and the team behind it

Our Project

PotatoPathFinder is an innovative college project designed to help farmers and agricultural researchers identify potato plant diseases using advanced image recognition technology. The system utilizes a convolutional neural network trained on extensive datasets of potato plant images to accurately detect and classify diseases.

Project Objectives

  • Develop an accessible tool for potato disease detection
  • Provide accurate and timely diagnosis of common potato diseases
  • Offer treatment recommendations based on detected conditions
  • Create an educational resource for agricultural students and researchers
  • Demonstrate the application of machine learning in agricultural domains

Technology Stack

Our project utilizes the following technologies:

Backend
  • Flask (Python web framework)
  • TensorFlow/Keras (ML modeling)
  • OpenCV (image processing)
  • SQLAlchemy (database ORM)
Frontend
  • HTML/CSS
  • Bootstrap 5
  • Vanilla JavaScript
  • Chart.js (data visualization)

Project Details

Academic Project

This is a college assignment created as part of our computer science curriculum.

Project Timeline

The project was developed during the 2023 academic year as our final submission.

Features Implemented
  • Image upload and preprocessing pipeline
  • Disease classification model
  • Result visualization and explanation
  • Treatment recommendation system
  • Historical detection data storage and analysis
Future Enhancements
  • Mobile application development
  • Integration with IoT devices for field monitoring
  • Expanded disease catalog with more varieties
  • Multilingual support for global accessibility
